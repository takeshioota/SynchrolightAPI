## 概要

SynchrolightAPI は、2.4GHz無線でLEDコンサートライトを制御するHTTP APIサーバーです。  
WPFアプリケーション（操作UI）から本APIを経由して、送信機→受信機→LEDの制御を行います。

### システム構成

```
WPF (操作UI) → HTTP API (localhost:5100) → シリアル通信 (COM) → 2.4G送信機 → LED受信機
```

### 機能一覧

| カテゴリ | 機能 |
|---|---|
| Transport | COMポートの接続・切断・状態監視・送信ログ |
| Transmitter | チャンネル・出力設定 |
| Light | グローバル色・行/列/ポイント/ブロック単位の色制御（連続送信） |
| Effect | 点滅・フェード・呼吸・7色変化エフェクト（完了後自動保持） |
| Sequence | シーケンスのCRUD・再生・記録・エディタ連携 |

### 連続送信アーキテクチャ（v20260513追加）

シンクロライトは **0.2秒以内にコマンドを受信しないとセルフモードに入る** ため、全てのLED制御コマンドは **20ms間隔で連続送信** されます。

- **色コマンド（Light API）**: 送信後、同じパケットを20ms間隔で送信し続ける。次のコマンドで自動切替。
- **エフェクト**: 実行中は各フレームを20ms間隔で送信。完了後は最終色を自動保持。
- **停止**: `POST /api/effect/stop` で全送信を完全停止。

```
後だし優先の原則:
赤点灯 → (赤を20ms間隔で送信中) → 緑点灯 → (赤を自動停止、緑に切替)
FadeIn → (補間フレーム送信中) → 完了 → (最終色を自動保持)
任意のコマンド → 停止ボタン → (全送信停止)
```

## 利用方法

### 起動手順

1. **APIサーバーを起動**: `publish/Api/SynchrolightAPI.Api.exe` を実行
2. **WPFアプリを起動**: `publish/Wpf/SynchrolightAPI.Wpf.exe` を実行（APIが未起動なら自動起動）
3. WPFが自動的に全COMポートをスキャン・接続し、送信機を初期化

### 基本的な操作フロー

```
1. COMポート接続        POST /api/transport/connect
2. 送信機初期化          POST /api/transmitter/init
3. LED制御              POST /api/light/global  (色設定 → 連続送信開始)
                        POST /api/effect/start  (エフェクト開始)
4. シーケンス再生        POST /api/sequence/play
5. 停止                 POST /api/effect/stop   (全送信停止)
6. 終了時               POST /api/transport/disconnect
```

### 本番シナリオ例（コンサート運用）

```bash
# 1. 消灯コマンド連続発行（セルフモード→2.4Gモードへ切替）
curl -X POST http://localhost:5100/api/light/off
# → A2(0,0,0) を20ms間隔で送信し続ける

# 2. 赤点灯（前の消灯は自動停止）
curl -X POST http://localhost:5100/api/light/global \
  -H "Content-Type: application/json" \
  -d '{"color": {"r": 255, "g": 0, "b": 0}}'

# 3. 色切替（後だし優先：緑→青→白→消灯）
curl -X POST http://localhost:5100/api/light/global \
  -H "Content-Type: application/json" \
  -d '{"color": "green"}'

# 4. 全消灯維持（アーティスト入場まで）
curl -X POST http://localhost:5100/api/light/off

# 5. FadeIn（消灯→緑）→ 完了後自動的に緑を保持
curl -X POST http://localhost:5100/api/effect/start \
  -H "Content-Type: application/json" \
  -d '{"type": "FadeIn", "color": {"r": 0, "g": 255, "b": 0}, "cycleDurationMs": 3000, "continuous": false}'
# → 3秒かけて黒→緑にフェード → 完了後、緑を20ms間隔で送信し続ける

# 6. FadeOut（緑→黒）→ 完了後自動的に消灯保持
curl -X POST http://localhost:5100/api/effect/start \
  -H "Content-Type: application/json" \
  -d '{"type": "FadeOut", "color": {"r": 0, "g": 255, "b": 0}, "cycleDurationMs": 2000, "continuous": false}'
# → 2秒かけて緑→黒にフェード → 完了後、黒を20ms間隔で送信し続ける

# 7. Flash（点滅）
curl -X POST http://localhost:5100/api/effect/start \
  -H "Content-Type: application/json" \
  -d '{"type": "Flash", "color": {"r": 255, "g": 255, "b": 255}, "flashIntervalMs": 200}'

# 8. 全停止（送信完全停止）
curl -X POST http://localhost:5100/api/effect/stop
```

### curlによる利用例

```bash
# 全LEDを赤に設定（20ms間隔で連続送信）
curl -X POST http://localhost:5100/api/light/global \
  -H "Content-Type: application/json" \
  -d '{"color": {"r": 255, "g": 0, "b": 0}}'

# フィールド指定（field=1: ID書込済端末のみ対象）
curl -X POST http://localhost:5100/api/light/global \
  -H "Content-Type: application/json" \
  -d '{"color": "red", "field": 1}'

# 呼吸エフェクト開始
curl -X POST http://localhost:5100/api/effect/start \
  -H "Content-Type: application/json" \
  -d '{"type": "Breathing", "color": {"r": 0, "g": 255, "b": 0}, "cycleDurationMs": 3000}'

# 全消灯（20ms間隔で連続送信）
curl -X POST http://localhost:5100/api/light/off

# 全停止（送信完全停止）
curl -X POST http://localhost:5100/api/effect/stop
```

## 注意事項

### 通信関連

- **連続送信**: 全ての色コマンド（Light API）は20ms間隔で連続送信される。デバイスの200msタイムアウト（セルフモード突入）を防止するため
- **後だし優先**: 新しいコマンドを発行すると、前のコマンドの連続送信は自動停止される
- **完全停止**: `POST /api/effect/stop` で全ての送信（色コマンド・エフェクト・シーケンス）を停止
- **COMポートの排他制御**: 1つのCOMポートは1プロセスのみが使用可能。他のアプリ（ターミナルソフト等）が使用中だと接続に失敗する
- **再送回数**: デフォルト3回。無線通信のため、パケットロスを考慮した再送が行われる。コマンド単位で `retransmitCount` を指定可能
- **キューフラッシュ**: エフェクト切替・停止時にキューがフラッシュされる。連続した高速リクエストでは中間のコマンドが破棄される場合がある
- **自動再接続**: COMポート切断時はバックグラウンドで自動再接続を試行（指数バックオフ: 5s→10s→20s、最大3回）

### エフェクト・シーケンス関連

- **排他制御**: エフェクトとシーケンスは排他的に動作。新しいエフェクト/シーケンス/色コマンドを開始すると、実行中のものは自動停止される
- **エフェクト完了後の自動保持**: `continuous=false` のエフェクトが正常完了した場合、最終色を自動的に連続送信する（セルフモード突入防止）
  - FadeIn完了 → 目標色を保持
  - FadeOut完了 → 黒（消灯）を保持
  - Flash完了 → 黒を保持
  - Breathing完了 → 黒を保持
- **EffectStop不要**: Color/Off/Effect コマンド実行時に前のエフェクトは自動停止される。EffectStop ステップは明示的な停止が必要な場合のみ使用
- **シーケンスファイル**: `sequences/` ディレクトリにJSON形式で保存。APIサーバーの実行ディレクトリ直下に配置
- **時間精度**: シーケンスの時間制御はミリ秒単位。ただし無線通信遅延（数ms〜数十ms）は含まれない

### API呼び出し関連

- **同時リクエスト**: 同一ステップの高速連続呼び出しはデバウンス処理（30ms）により最新のみ実行
- **JSONシリアライズ**: プロパティ名はcamelCase、列挙型は文字列表現
- **色指定**: RGB値オブジェクト `{"r":255,"g":0,"b":0}` またはプリセット名 `"red"` のいずれかで指定可能

## 共通仕様

### 共通レスポンス構造

全APIは以下の共通レスポンス構造を返します。

```json
{
  "success": true,
  "message": "操作結果メッセージ",
  "error": null,
  "data": { ... }
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| `success` | bool | 成功: true / 失敗: false |
| `message` | string\|null | 成功時のメッセージ |
| `error` | string\|null | 失敗時のエラー詳細 |
| `data` | object\|null | レスポンスデータ（エンドポイントにより異なる） |

### 色指定 (ColorValue)

色は以下の2つの形式で指定できます。

**RGB値指定:**
```json
{"r": 255, "g": 128, "b": 0}
```

**プリセット名指定:**

| プリセット名 | RGB値 |
|---|---|
| `"red"` | (255, 0, 0) |
| `"green"` | (0, 255, 0) |
| `"blue"` | (0, 0, 255) |
| `"white"` | (255, 255, 255) |
| `"black"` | (0, 0, 0) |

## APIリファレンス

## 1. Transport（通信管理）

ベースパス: `/api/transport`

### GET /api/transport/scan

利用可能なCOMポートをスキャンして一覧を返します。

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "ports": ["COM3", "COM4", "COM5"]
  }
}
```

---

### POST /api/transport/connect

指定したCOMポートに接続します。

**リクエスト:**
```json
{
  "portNames": ["COM3", "COM4"]
}
```

**レスポンス:**
```json
{
  "success": true,
  "message": "2 port(s) connected",
  "data": {
    "connectedPorts": [
      {"portName": "COM3", "isConnected": true, "lastError": null},
      {"portName": "COM4", "isConnected": true, "lastError": null}
    ]
  }
}
```

---

### POST /api/transport/disconnect

全COMポートを切断します。

**リクエスト:** なし

**レスポンス:**
```json
{"success": true, "message": "Disconnected"}
```

---

### GET /api/transport/status

接続状態・送信キューの状態を取得します。

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "queueLength": 0,
    "highPriorityQueueLength": 0,
    "connectedPorts": 4,
    "disconnectedPorts": 0,
    "lastError": null,
    "ports": [
      {"name": "COM3", "isConnected": true}
    ]
  }
}
```

---

### GET /api/transport/log

送信ログを取得します（ポーリング方式）。

**クエリパラメータ:**

| パラメータ | 型 | 説明 |
|---|---|---|
| `afterSeq` | long | このシーケンス番号より後のログを取得 |
| `count` | int | 取得件数（デフォルト: 100） |

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "entries": [
      {
        "seq": 1,
        "timestampUtc": "2026-05-10T10:30:45Z",
        "direction": "Send",
        "portName": "COM3",
        "base64": "QTIwMEZGMDAwMA==",
        "parsed": "A2 Global Color: (255,0,0)"
      }
    ]
  }
}
```

---

### GET /api/transport/log/stream

送信ログのリアルタイムストリーム（SSE: Server-Sent Events）。

**レスポンス形式:** `text/event-stream`

```
data: {"seq":1,"timestampUtc":"...","direction":"Send","portName":"COM3","base64":"...","parsed":"..."}

```

---

### POST /api/transport/keepalive

指定パケットを送信します（キープアライブ・再送用）。

**リクエスト:**
```json
{
  "base64Packet": "QTIwMEZGMDAwMA=="
}
```

**レスポンス:**
```json
{"success": true, "message": "Keep-alive sent"}
```

## 3. Light（LED制御）

ベースパス: `/api/light`

> **連続送信**: 全ての色コマンドは即座にレスポンスを返し、バックグラウンドで20ms間隔の連続送信を開始します。新しいコマンド発行または `POST /api/effect/stop` で自動停止します。

### POST /api/light/global

全LEDをグローバル色に設定します（A2コマンド）。20ms間隔で連続送信。

**リクエスト:**
```json
{
  "color": {"r": 255, "g": 0, "b": 0},
  "field": 0
}
```

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `color` | ColorValue | Yes | 色指定 |
| `field` | int | No | フィールド値（デフォルト: 0）。0=ブロードキャスト、1=ID書込済端末 |

---

### POST /api/light/off

全LEDを消灯します（A2コマンド、色=黒）。20ms間隔で連続送信。

**リクエスト:** なし

**動作**: RGB(0,0,0)を20ms間隔で連続送信。セルフモード突入を防止しつつ消灯状態を維持。

---

### POST /api/light/rows

複数行を同一色に設定します（AAコマンド）。20ms間隔で連続送信。

**リクエスト:**
```json
{
  "field": 0,
  "startRow": 0,
  "rowLen": 8,
  "color": {"r": 255, "g": 0, "b": 0}
}
```

---

### POST /api/light/rows/each

各行を個別色に設定します（A3コマンド）。20ms間隔で連続送信。

**リクエスト（個別色指定）:**
```json
{
  "field": 0,
  "startRow": 0,
  "colors": [
    {"r": 255, "g": 0, "b": 0},
    {"r": 0, "g": 255, "b": 0},
    {"r": 0, "g": 0, "b": 255}
  ]
}
```

**リクエスト（範囲+単色）:**
```json
{
  "field": 0,
  "startRow": 0,
  "len": 8,
  "color": "red"
}
```

---

### POST /api/light/cols

複数列を同一色に設定します（A8コマンド）。20ms間隔で連続送信。

**リクエスト:**
```json

  "field": 0,

  "colLen": 8,

```

## 4. Effect（エフェクト）

ベースパス: `/api/effect`

### POST /api/effect/start

エフェクトを開始します。実行中のエフェクト/シーケンス/色コマンドの連続送信は自動停止されます。

**リクエスト:**
```json
{
  "type": "Breathing",
  "color": {"r": 255, "g": 0, "b": 0},
  "field": 0,
  "cycleDurationMs": 3000,
  "flashIntervalMs": null,
  "fadeSteps": 20,
  "continuous": true
}
```

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `type` | string | Yes | エフェクト種別（後述） |
| `color` | ColorValue | Yes | 色指定 |
| `field` | int | No | フィールド値（デフォルト: 0） |
| `cycleDurationMs` | int | No | 1サイクルの時間（ms）。Flash以外のエフェクトで使用 |
| `flashIntervalMs` | int | No | Flash用ON/OFF間隔（ms）。未指定時は `cycleDurationMs / 2` |
| `fadeSteps` | int | No | 補間ステップ数（デフォルト: 20） |
| `continuous` | bool | No | 繰り返し実行（デフォルト: true） |

**continuous パラメータの動作:**

| continuous | 動作 |
|---|---|
| `true`（デフォルト） | エフェクトを無限繰り返し。停止コマンドまで継続 |
| `false` | エフェクトを1回実行後、**最終色を自動的に連続送信（保持）** |

**continuous=false 時の最終色自動保持:**

| エフェクト | 最終色 | 例 |
|---|---|---|
| FadeIn | 目標色 | 黒→緑 → 緑を保持 |
| FadeOut | 黒 | 緑→黒 → 黒（消灯）を保持 |
| Flash | 黒 | ON/OFF終了 → 黒を保持 |
| Breathing | 黒 | 呼吸終了 → 黒を保持 |
| SevenColor | 白 | 7色変化終了 → 白を保持 |

---

### POST /api/effect/stop

実行中のエフェクト・色コマンドの連続送信を全て停止します。

**リクエスト:** なし

**動作**: エフェクトのバックグラウンドタスク、色コマンドの連続送信、スケジューラーを全停止。送信キューもフラッシュされる。

---

### GET /api/effect/status

エフェクトの実行状態を取得します。

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "isRunning": true,
    "effectType": "Breathing",
    "color": {"r": 255, "g": 0, "b": 0}
  }
}
```

| フィールド | 説明 |
|---|---|
| `isRunning` | エフェクトまたは色コマンドの連続送信が動作中 |
| `effectType` | 実行中のエフェクト種別（色コマンド保持時はnull） |
| `color` | 実行中のエフェクトの色（色コマンド保持時はnull） |

## 5. Sequence（シーケンス）

ベースパス: `/api/sequence`

### GET /api/sequence

保存済みシーケンス名の一覧を取得します。

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "names": ["10色エフェクトデモ", "カウントダウン3秒"]
  }
}
```

---

### GET /api/sequence/{name}

指定名のシーケンスを取得します。

**パスパラメータ:** `name` - シーケンス名（URLエンコード必須）

**レスポンス:**
```json
{
```

## 列挙型・型定義

### EffectType（エフェクト種別）

| 値 | 説明 | continuous=false時の最終色 |
|---|---|---|
| `Flash` | 点滅（ON→OFF→ON→OFF） | 黒 |
| `FadeIn` | フェードイン（黒→色） | 目標色 |
| `FadeOut` | フェードアウト（色→黒） | 黒 |
| `Breathing` | 呼吸（FadeIn→FadeOut を繰り返し） | 黒 |
| `SevenColor` | 7色変化（赤→黄→緑→シアン→青→マゼンタ→白） | 白 |

### SequenceCommandType（シーケンスコマンド種別）

| 値 | 説明 | 連続送信 |
|---|---|---|
| `Color` | グローバル色設定（A2コマンド） | 20ms間隔で連続送信 |
| `Off` | 消灯 | 20ms間隔で連続送信 |
| `Effect` | エフェクト開始（effectType指定必須） | エフェクト実行中は連続送信、完了後は最終色保持 |
| `EffectStop` | エフェクト停止（通常は不要、自動停止あり） | 送信停止 |

### SequenceStep（シーケンスステップ）

| フィールド | 型 | 説明 |
|---|---|---|
| `timeOffsetMs` | int | シーケンス開始からの経過時間（ms） |
| `commandType` | string | コマンド種別 |
| `r`, `g`, `b` | byte | RGB値（0〜255） |
| `field` | byte | フィールド値（デフォルト: 0） |
| `retransmitCount` | int\|null | 再送回数（null=グローバル設定に従う） |
| `effectType` | string\|null | エフェクト種別（commandType=Effect時のみ） |
| `effectCycleDurationMs` | int\|null | エフェクト周期（ms）。Flash時はON/OFF間隔 = 値/2 |
| `fadeSteps` | int\|null | 補間ステップ数 |
